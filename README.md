### （1）题目白话文解释

题目的核心诉求是：给定一排整数，要求从中挑选出若干个数字，**保持它们在原数组中的先后顺序不变**，并且挑出来的这些数字必须是**一个比一个大**（严格递增）。目标是算出最多能挑出多少个这样的数字。

**生僻/关键概念解释：**
* **子序列 (Subsequence)**：与“子数组”不同，子序列**不要求连续**。例如，在数组 `[3, 6, 2, 7]` 中，`[3, 6, 7]` 就是一个子序列，因为它们在原数组里的相对前后顺序没有乱。
* **严格递增**：后一个数字必须绝对大于前一个数字。如果是相等的（例如 `[2, 2, 3]`），则不符合要求。

### （2）代码解题思路来源

这段代码采用的是 **动态规划 (Dynamic Programming)** 结合 **二分查找 (Binary Search)** 的算法，在算法界通常被称为 **“耐心排序” (Patience Sorting)** 思想。

解题思路的核心在于维护一个名为 `tails` 的数组。
* `tails[k]` 存储的是：在所有长度为 `k+1` 的递增子序列中，**结尾数字最小的那个数**。
* **为什么要找结尾最小的？** 因为结尾的数字越小，后续能接上更大数字的概率就越高，这个子序列“变长”的潜力就越大。

**核心执行逻辑如下：**
1.  遍历原数组里的每一个数字 `num`。
2.  用 `num` 去和 `tails` 数组里已经存在的数字进行比较。为了加快查找速度，使用了二分查找。
3.  二分查找的目的，是在 `tails` 数组中找到**第一个大于或等于 `num` 的数字**，并将其替换为 `num`。
    * **如果替换了中间的某个数**：说明找到了一个具有同样长度、但结尾更小的子序列。最长子序列的总长度没有变，但未来的潜力变大了。
    * **如果 `num` 比 `tails` 里所有的数都要大**：说明这个 `num` 可以接在当前最长子序列的最后面，从而诞生了一个更长的递增子序列，此时记录最大长度的变量 `res` 会加一。

### （3）带有注释的代码

```python
# Dynamic programming + Dichotomy.
class Solution:
    def lengthOfLIS(self, nums: [int]) -> int:
        # 初始化 tails 数组（长度与 nums 相同），以及记录最长长度的 res
        tails, res = [0] * len(nums), 0
        # 遍历数组中的每一个数字
        for num in nums:
            # 设定二分查找的左右边界，i 为左边界，j 为右边界（即当前有效长度）
            i, j = 0, res
            # 执行二分查找，寻找第一个大于等于 num 的位置
            while i < j:
                # 计算中点索引 m
                m = (i + j) // 2
                # 如果中点值小于 num，说明目标位置在右半边
                if tails[m] < num: 
                    i = m + 1 # 如果要求非严格递增，将此行 '<' 改为 '<=' 即可。
                # 否则说明目标位置在左半边（包含中点自身）
                else: 
                    j = m  
            # 将 num 放入找到的位置 i，更新（或延伸）tails 数组
            tails[i] = num
            # 如果找到的位置刚好等于当前的最长长度 res，说明子序列长度增加了
            if j == res: 
                res += 1
        # 返回最终的最长递增子序列长度
        return res
```

### （4）每一行代码详细解释

1.  `# Dynamic programming + Dichotomy.`：原作者注释，说明使用的是动态规划加二分法（Dichotomy即二分法）。
2.  `class Solution:`：定义执行类。
3.  `def lengthOfLIS(self, nums: [int]) -> int:`：定义核心函数，接收整数列表 `nums`，返回整数类型的长度结果。
4.  `tails, res = [0] * len(nums), 0`：并行赋值初始化。创建一个名为 `tails` 的一维数组，长度等于原数组 `nums` 的长度，初始值全为 `0`（因为最坏情况下，递增子序列的长度就是原数组全长）。同时初始化变量 `res` 为 `0`，用来动态记录当前已发现的最长递增子序列的有效长度。
5.  `for num in nums:`：启动外层循环，逐一取出原数组 `nums` 中的每一个整数赋给变量 `num` 进行处理。
6.  `i, j = 0, res`：在每次开始考察新数字 `num` 时，初始化二分查找的指针。`i` 是搜索区间的左端点（起始索引 `0`），`j` 是搜索区间的右端点（设定为当前的有效长度 `res`，这是一个开区间边界）。
7.  `while i < j:`：启动内层循环（二分查找的核心）。只要左指针 `i` 还没有追上右指针 `j`，就继续缩小搜索范围。
8.  `m = (i + j) // 2`：计算当前左右指针中间位置的索引 `m`。`//` 表示整数除法（向下取整）。
9.  `if tails[m] < num:`：判断 `tails` 数组在中间位置记录的值是否严格小于当前考察的 `num`。
10. `i = m + 1`：如果中点值小于 `num`，说明 `num` 应该被安放在更靠右的位置。因此将左边界 `i` 收缩到 `m + 1`。（后附注释提到若找非严格递增可改为 `<=`）。
11. `else:`：如果中点值大于或等于 `num`。
12. `j = m`：说明 `num` 应该替换掉左半边（或中点）的某个较大值，以降低该长度子序列的结尾数值。因此将右边界 `j` 移动到中点 `m`。
13. `tails[i] = num`：当 `while` 循环结束时，`i` 和 `j` 相等，此时的 `i` 就是 `num` 应该放置的确切索引位置。用 `num` 覆盖更新 `tails[i]` 的值。
14. `if j == res:`：判断刚才进行二分查找的初始右边界 `j`（也就是本次存放数字前记录的最长长度）是否等于当前的放置位置（由于循环结束时 `i == j`，且如果没有执行过 `j = m`，`j` 会一直保持等于初始的 `res`）。
15. `res += 1`：如果条件成立，说明刚才的 `num` 比 `tails` 中有效范围内的所有数字都大，被添加到了有效范围的最末尾。这意味着最长递增子序列的长度增加了一位，因此将 `res` 加一。
16. `return res`：当外层 `for` 循环把所有数字都考察完毕后，返回记录的最终长度 `res`。

### （5）具体数值算例及变量变化表格

下面提供一个简化的算例进行详细跟踪。设给定数组 `nums = [10, 9, 2, 5, 3]`。
初始状态：`tails = [0, 0, 0, 0, 0]`, `res = 0`。

| 执行阶段 | 当前 `num` | `i, j, m` 的变化过程 (二分查找) | 逻辑判断结果 | `tails` 数组状态 | `res` | 对应执行代码行 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **初始** | - | - | - | `[0, 0, 0, 0, 0]` | `0` | `tails, res = [0] * len(nums), 0` |
| **处理10** | `10` | `i=0, j=0` | `i<j` 不成立，不进 while | `tails[0] = 10` <br> `[10, 0, 0, 0, 0]` | `1` | `tails[i] = num` <br> `if j==res: res+=1` |
| **处理9** | `9` | `i=0, j=1` -> `m=0` | `tails[0](10) < 9` 假，执行 `j=m(0)` | `tails[0] = 9` <br> `[9, 0, 0, 0, 0]` | `1` | `else: j = m` <br> `tails[i] = num` |
| **处理2** | `2` | `i=0, j=1` -> `m=0` | `tails[0](9) < 2` 假，执行 `j=m(0)` | `tails[0] = 2` <br> `[2, 0, 0, 0, 0]` | `1` | `else: j = m` <br> `tails[i] = num` |
| **处理5** | `5` | `i=0, j=1` -> `m=0` | `tails[0](2) < 5` 真，执行 `i=m+1(1)` | `tails[1] = 5` <br> `[2, 5, 0, 0, 0]` | `2` | `if tails[m] < num: i = m + 1` <br> `tails[i] = num` <br> `if j==res: res+=1` |
| **处理3** | `3` | ① `i=0, j=2` -> `m=1` | `tails[1](5) < 3` 假，执行 `j=m(1)` | - | - | `else: j = m` |
| | | ② `i=0, j=1` -> `m=0` | `tails[0](2) < 3` 真，执行 `i=m+1(1)` | `tails[1] = 3` <br> `[2, 3, 0, 0, 0]` | `2` | `if tails[m] < num: i = m + 1` <br> `tails[i] = num` |
| **结束** | - | - | - | - | `2` | `return res` |

*(注：通过 `tails` 数组的不断替换，虽然 `3` 替换了 `5` 并没有增加总长度，但它让长度为 2 的子序列结尾变成了更小的 `3`，如果数组后面还有数字 `4`，就能接在 `3` 后面形成 `[2, 3, 4]`。这就是耐心排序的精髓。)*
